# SKYBLOOD narration audio

The comic reader now looks for one MP3 narration track per page.

Path format:

`/audio/s{season}/i{issue}/p{page}.mp3`

Examples for Season 1, Issue 1:

- `public/audio/s1/i01/p01.mp3`
- `public/audio/s1/i01/p02.mp3`
- `public/audio/s1/i01/p03.mp3`
- ...
- `public/audio/s1/i01/p32.mp3`

Until a page MP3 exists, the reader displays **Narration coming soon**.

Narration should preserve SKYBLOOD sound canon. In Issue #1, the silent strike removes ambient sound after the strike; narration/dialogue decisions should not reintroduce ambient sound where the comic intentionally removes it.
